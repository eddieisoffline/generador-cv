# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
([en español](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)).

En resumen: queremos que participar en el proyecto sea una experiencia libre de
acoso para todas las personas. Se espera un trato respetuoso, críticas
constructivas centradas en el trabajo y aceptar con buena disposición las
correcciones. No se toleran insultos, acoso, ataques personales ni la publicación
de datos privados de otras personas.

## Aplicación

Para informar de un comportamiento inaceptable, escribe a
**e.ddieag451@outlook.com**. Todas las denuncias se revisarán con
confidencialidad. Las consecuencias se aplican según las
[pautas de aplicación](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
del Contributor Covenant.
